📅 Выдать / продлить подписку

Пользователь должен сначала запустить бот.

Если у пользователя есть активная подписка — срок будет продлён, не перезаписан. Бонусные дни (если накоплены) применятся автоматически.

🎁 Создать промокод

Скидка снижает итоговую сумму платежа в %. Один пользователь может использовать промокод только один раз.

🎁 Начислить бонусные дни

Если у пользователя активная подписка — дни добавятся к ней. Если нет — сохранятся в копилке и применятся при следующей оплате.
